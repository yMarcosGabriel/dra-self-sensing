# Self-sensing dielectric resonator antenna: inverse material estimation

This repository contains a compact numerical dataset and Python scripts supporting the regression analysis of the manuscript **“Numerical assessment of a self-sensing dielectric resonator antenna for permittivity and loss-tangent estimation.”**

The study estimates the relative permittivity and dielectric loss tangent of a fixed-geometry rectangular dielectric resonator antenna from features of a single-port reflection response. The dataset was generated by full-wave simulations in Ansys HFSS; it does **not** contain experimental measurements.

## Contents

- `data/dataset.csv`: 335 accepted simulation responses, in the consolidated row order used for cross-validation.
- `src/train_evaluate.py`: 10-fold out-of-fold evaluation of separate multilayer perceptrons for relative permittivity (L-BFGS) and loss tangent (Adam).
- `src/plot_predictions.py`: parity and residual plots derived from the predictions.
- `requirements.txt`: Python dependencies.

The dataset has 12 columns. The regression uses five extracted response features (`f_res_ghz`, `s11_min_db`, `q_factor`, `re_z11_ohm`, `im_z11_ohm`) and two material targets (`er`, `tan_delta`). The dimensions `a_mm`, `b_mm`, and `d_mm` are fixed at 20, 18, and 14 mm. `q_factor` is calculated from the −10 dB bandwidth and should not be interpreted as an independently measured energy-based quality factor. The remaining columns document the sweep and response.

## Reproduce the regression evaluation

Python 3.10 or later is recommended.

```bash
python -m venv .venv
# Activate the virtual environment using your operating system's instructions.
pip install -r requirements.txt
python src/train_evaluate.py --check
python src/train_evaluate.py
python src/plot_predictions.py
```

The evaluation writes `outputs/cv_predictions.csv`, `outputs/cv_metrics.json`, and `outputs/parity_residuals.pdf`. The `outputs/` directory is intentionally excluded from version control.

The training script uses the same feature set, log-transformed quality metric and loss-tangent target, MLP architecture (128, 64, 64, 32), L-BFGS for permittivity and Adam with early stopping for loss tangent, and shuffled 10-fold splits (seed 42) as the consolidated notebook. Input and target scalers are fitted **within each training fold**, avoiding leakage. Small numerical differences can occur between Python/scikit-learn versions. The manuscript's reported metrics refer to its consolidated analysis run, not necessarily bit-for-bit output in every environment.

## Scope and limitations

This deposit supports independent inspection of the accepted simulation dataset and reproduction of the main regression evaluation. It does **not** include HFSS projects, raw frequency-sweep traces, field solutions, mesh files, rejected simulations, or the separate datasets for mounting, mesh convergence, material examples, and synthetic noise. Consequently, it does not permit full regeneration of the electromagnetic simulations or every table and figure in the manuscript. The full simulation campaign requires the electromagnetic model and associated setup.

The dataset contains synthetic full-wave simulation responses rather than measurements of physical material samples. The model's numerical accuracy must not be interpreted as demonstrated experimental accuracy.
